# Stocknex 📈

Stocknex is a web-based stock market application designed to provide users with a simple and intuitive platform for exploring stock market information, tracking stocks, and understanding market trends.

The project focuses on building a clean user experience while working with real-world financial data and developing practical full-stack web development skills.

## 🚀 Features

* 📊 View stock market information
* 🔎 Search and explore stocks
* 📈 Track stock prices and market trends
* 💹 Display relevant stock-related data
* 🖥️ Responsive and user-friendly interface
* ⚡ Fast and simple navigation

## 🛠️ Tech Stack

**Frontend**

* HTML

**Backend**

* Node.js

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Stocknex.git
```

### 2. Navigate to the project

```bash
cd Stocknex
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and add the required environment variables.

Example:

```env
MONGO_URI=your_mongodb_connection_string
API_KEY=your_api_key
```

Do **not** commit your `.env` file to GitHub.

### 5. Start the application

```bash
npm start
```

Or, if using nodemon:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```
